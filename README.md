# Library Management System (Using OOP in Java)

## 📌 Objective  
The goal of this project is to develop a mini *Library Management System* using *Object-Oriented Programming (OOP)* concepts in Java.  
It helps understand core OOP principles like Abstraction, Inheritance, Polymorphism, and Encapsulation.

---

## 🛠 Tools Used  
- *Java JDK*  
- *VS Code*  
- *Terminal/Command Prompt*  

---

##  Project Structure  
This project contains the following files:  

1. *Book.java* → Represents a book in the library  
2. *User.java* → Represents a user of the library  
3. *Library.java* → Manages books, issuing, and returning  
4. *Main.java* → Main program to run the application  

---

##  Features Implemented  
- Add books to the library  
- Display all books with status (Available/Issued)  
- Issue a book to a user  
- Return a book to the library  

---

## How to Run the Project  
1. Open VS Code or Command Prompt
